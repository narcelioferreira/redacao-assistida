## Limitações
- O CI e o CD **ainda não rodaram no GitHub**: tudo foi verificado localmente.
- A imagem foi construída com uma cópia adaptada do Dockerfile, porque este ambiente não baixa do
  Docker Hub nem do GHCR. As imagens base têm o mesmo digest, mas o build com o Dockerfile original só
  acontece no CI.
- O bootstrap passou por `bash -n` e shellcheck, mas **não foi executado no Azure** (T07).
- O zizmor rodou offline: ficaram de fora as auditorias que consultam a API do GitHub.
- Riscos residuais: seção 7 de `docs/03-seguranca.md`.
