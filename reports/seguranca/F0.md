### Limitações

- O CI e o CD **ainda não rodaram no GitHub**: tudo foi verificado localmente.
- A imagem foi construída com uma cópia adaptada do Dockerfile, porque este ambiente não baixa do
  Docker Hub nem do GHCR. As imagens base têm o mesmo digest, mas o build com o Dockerfile original só
  acontece no CI.
- O bootstrap passou por `bash -n` e shellcheck, mas **não foi executado no Azure** (T07 depende da
  conta).
- `zizmor` rodou no modo offline: as auditorias que consultam a API do GitHub ficaram de fora.

### Riscos residuais

Os da seção 7 de `docs/03-seguranca.md`: API do demo pública sem login (só `/health` e `/docs` até a
T13), confiança na plataforma do GitHub, bootstrap com privilégio de dono.

   fazer no Azure?

3. Por que o smoke test confere o SHA, e não só o status 200?
4. O que a mutação M18 prova, e por que um teste que "sempre passa" não comprova nada?
5. O que acontece se a exceção do `certifi` não for removida até 03/11?
